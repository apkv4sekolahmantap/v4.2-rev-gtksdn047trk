# Apk Sekolah Mantap v4.0
Frontend (GitHub Pages) untuk backend Google Apps Script. Lihat `PANDUAN-INSTALASI.md`.
Berkas: `index.html`, `css/style.css`, `js/config.js` (isi URL /exec), `js/app.js` (inti), `js/modules.js` (navigasi & CRUD), `js/pages.js` (halaman khusus), `js/games.js` (game), `js/tools.js` (alat pembelajaran).
